TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

Problem: Server won't start
Solution:
  - Check MongoDB is running
  - Check port 1008 is available
  - Verify .env file exists

Problem: "Cannot GET /api/resumes"
Solution:
  - Ensure server is running on port 1008
  - Check exact endpoint URL
  - Verify request method (GET vs POST)

Problem: File upload fails
Solution:
  - Use Postman form-data, not raw JSON
  - Select file type as "file" in Postman
  - Ensure file is PDF/DOC/DOCX

Problem: MongoDB connection error
Solution:
  - Start MongoDB daemon
  - Check connection string in .env
  - For Atlas: Verify IP whitelist

Problem: Dependencies won't install
Solution:
  - Delete node_modules and package-lock.json
  - Run: npm install again
  - Try: npm install --legacy-peer-deps
