HOW TO USE THESE FILES
─────────────────────────────────────────────────────────────────

SCENARIO 1: I want to start the server
  1. Open terminal
  2. CD into /backend folder
  3. Run: npm start
  4. Server runs on http://localhost:1008

SCENARIO 2: I want to test APIs in Postman
  1. Open Postman
  2. Click "Import"
  3. Select "Resume_Job_Portal_API.postman_collection.json"
  4. All 16 endpoints are now ready to test
  5. Follow "QUICK_START_GUIDE.txt" for testing order

SCENARIO 3: I need to understand the APIs
  1. Read "README.md" for overview
  2. Read "CSE471_Assignment_API_Documentation.txt" for details
  3. Look at code snippets in documentation
  4. Check example requests/responses

SCENARIO 4: I need to modify/customize APIs
  1. Edit controller files in /backend/controllers/
  2. Edit route files in /backend/routes/
  3. Restart server: npm start
  4. Re-test in Postman

SCENARIO 5: I need to change database
  1. Edit /backend/.env
  2. Change MONGODB_URI value
  3. If using Atlas, paste your connection string
  4. Restart server: npm start
