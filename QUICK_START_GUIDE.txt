STEP 1: ENSURE MONGODB IS RUNNING
─────────────────────────────────────────────────────────────────

Option A - Local MongoDB:
  macOS:
    brew services start mongodb-community

  Windows:
    Services → MongoDB → Start

  Linux:
    sudo systemctl start mongod

Option B - MongoDB Atlas (Cloud):
  1. Create account at https://www.mongodb.com/cloud/atlas
  2. Create a cluster and get connection string
  3. Update .env file:
     MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/resume-job-portal

═════════════════════════════════════════════════════════════════

STEP 2: START THE SERVER
─────────────────────────────────────────────────────────────────

1. Open Terminal/Command Prompt
2. Navigate to backend directory:
   cd "backend"

3. Start the server:
   npm start

4. Verify server is running:
   ✓ Look for: "Server started successfully!"
   ✓ URL: http://localhost:1008
   ✓ Test: Open http://localhost:1008/api/health in browser

═════════════════════════════════════════════════════════════════

STEP 3: IMPORT POSTMAN COLLECTION
─────────────────────────────────────────────────────────────────

1. Open Postman application
2. Click "Import" button (top-left)
3. Select file: "Resume_Job_Portal_API.postman_collection.json"
4. Collection will appear in sidebar
5. Expand to see all organized endpoints

STEP 4: TEST APIs IN POSTMAN
─────────────────────────────────────────────────────────────────

FEATURE 01 - Resume Testing Order:
  1. POST /api/resumes/upload
     → Copy returned resumeId and save it

  2. POST /api/resumes/{resumeId}/parse
     → Use resumeId from step 1

  3. GET /api/resumes/{resumeId}

  4. GET /api/resumes/user/user-001

  5. PUT /api/resumes/{resumeId}

  6. GET /api/resumes/{resumeId}/download

  7. DELETE /api/resumes/{resumeId}


FEATURE 02 - Job Posting Testing Order:
  1. POST /api/jobs/create
     → Copy returned jobId and save it

  2. GET /api/jobs/{jobId}
     → Use jobId from step 1

  3. GET /api/jobs (with filters)

  4. GET /api/jobs/employer/employer-001

  5. PUT /api/jobs/{jobId}

  6. PUT /api/jobs/{jobId}/apply

  7. POST /api/jobs/search/skills

  8. PUT /api/jobs/{jobId}/close

  9. DELETE /api/jobs/{jobId}

COMMON ISSUES & SOLUTIONS
─────────────────────────────────────────────────────────────────

Issue: "Cannot connect to MongoDB"
Solution:
  - Ensure MongoDB is running (mongod service)
  - Check connection string in .env file
  - Test: mongosh or mongo command in terminal

Issue: "Port 1008 already in use"
Solution:
  - Change PORT in .env file
  - Or kill process: lsof -i :1008 | kill -9 <PID>

Issue: "npm install failed"
Solution:
  - Delete node_modules folder
  - Delete package-lock.json
  - Run: npm install again

Issue: "Cannot find module"
Solution:
  - Ensure all dependencies installed: npm install
  - Delete node_modules and reinstall

API RESPONSE FORMAT
─────────────────────────────────────────────────────────────────

All API responses follow this format:

Success Response (200, 201):
{
  "success": true,
  "message": "Description of success",
  "data": {
    // Response data
  }
}

Error Response (400, 404, 500):
{
  "success": false,
  "message": "Error description",
  "error": "Detailed error info"
}
