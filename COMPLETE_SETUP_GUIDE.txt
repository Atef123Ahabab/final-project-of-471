PART 4: VERIFY DATABASE CONNECTION
─────────────────────────────────────────────────────────────────

Option A - Local MongoDB (Default):
  Start MongoDB in a separate terminal:
    macOS: brew services start mongodb-community
    Windows: Services → Find MongoDB → Start
    Linux: sudo systemctl start mongod

  Test connection from project:
    $ mongosh
    Expected: Connected to mongodb://localhost:27017/

Option B - MongoDB Atlas (Cloud):
  1. Go to https://mongodb.com/cloud/atlas
  2. Create account and cluster
  3. Get connection string
  4. Edit /backend/.env:
       MONGODB_URI=mongodb+srv://user:pass@cluster.mongodb.net/resume-job-portal
  5. Save file

TROUBLESHOOTING DURING EXECUTION
─────────────────────────────────────────────────────────────────

Problem: "Cannot GET /api/resumes"
Fix:
  - Verify server is running (look for success message)
  - Check URL is exactly correct
  - Verify port 1008 in URL

Problem: "MongoDB connection failed"
Fix:
  - Start MongoDB: mongod (Mac) or via Services (Windows)
  - Or update .env with correct connection string

Problem: "Port 1008 already in use"
Fix:
  - Change port in .env file
  - Or kill existing process

Problem: "File upload returns 400"
Fix:
  - Use form-data, not raw JSON
  - Select file from computer
  - Check file is PDF/DOC/DOCX

Problem: "404 Not Found"
Fix:
  - Check exact endpoint spelling
  - Verify HTTP method (POST vs GET)
  - Check resource ID exists

Problem: "500 Internal Server Error"
Fix:
  - Check server console for error message
  - Verify request body JSON is valid
  - Check MongoDB is running
