Feature 01: Resume Upload & Parsing

Upload a PDF/DOC file, then extract skills and experience into the backend record.

What this front end does

This area is dedicated to the resume workflow. Users upload their file, then the page sends the file to the backend and stores parsed details.

  • Connects to POST /api/resumes/upload
  • Connects to POST /api/resumes/:resumeId/parse
  • Shows saved resumes for the selected user
  • Displays extracted skills beside the upload form

Feature 02: Job Posting & Management

Create, edit, search, and close job postings with required skills and qualifications.

What this front end does

This panel handles the employer workflow. Jobs can be created, edited, refreshed, and closed from one visible area.

  • Connects to POST /api/jobs/create
  • Connects to PUT /api/jobs/:jobId
  • Connects to PUT /api/jobs/:jobId/close
  • Lets employers review all posted jobs beside the form

Feature 03: Job Application System

Apply directly to a job and attach one of the uploaded resumes.

What this front end does

This section is for candidates. They choose an open job, attach a stored resume, and submit the application in one step.

  • Connects to PUT /api/jobs/:jobId/apply
  • Requires a selected resume before submission
  • Shows a preview of how the application payload is sent
  • Feeds the shortlist panel below
This panel sends PUT /api/jobs/:jobId/apply with resume attachment details and applicant data.
Switch to Candidate Shortlisting to inspect and manage applications for any job.

Feature 04: Candidate Shortlisting

Filter candidates by status, shortlist them, and remove them from the shortlist if needed.

What this front end does

This part is for employers reviewing applicants. It shows job candidates, status filters, and one-click shortlisting actions.

  • Connects to GET /api/jobs/:jobId/applications
  • Connects to PUT /api/jobs/applications/:applicationId/status
  • Supports shortlist and remove-shortlist actions
  • Shows filtered candidate views beside the controls
